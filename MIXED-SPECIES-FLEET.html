02 · Control plane

Priority, dispatch, and judgment stay separate

The fleet moves quickly because each role has a narrow authority—not because one session silently absorbs the others.

Plan ranks

Owns queue order, bounded stage scope, acceptance criteria, and dependencies. It never dispatches implementation processes.

Boss admits

Owns health, quota, time locks, identity checks, dispatch, exact publication, and effect verification. It does not invent project counter-theories.

Worker judges

Owns domain decisions inside the ranked boundary, produces the artifact, and names concrete blockers. Findings return to Plan as facts.

03 · Stage state machine

One artifact moves through seven gates

Process absence never determines outcome. The artifact, its evidence, and its publication receipt do.

01

Ranked

Immutable Plan reference, stage ID, scope, criteria, dependencies.

02

Admitted

Boss checks quota, time, worker health, path collision, and route eligibility.

03

Identified

Requested selector, transcript-exposed model, and any independent proxy-side provider attestation recorded separately.

04

Running

Worker owns bounded execution. Checkpoints precede any reroute.

05

Evidence

Diff/output, tests, controls, exit codes, quota snapshot, clean state.

06

Reviewed once

One independent verdict. One same-writer fix pass; mechanical gates rerun; no re-review.

07

Published

Exact reviewed artifact is published and live effect is independently verified.

blocked

Preserve worker and artifact state. Name the mechanism. Plan corrects authority only after the complete evidence corpus closes.

finding fix

The same writer gets at most one narrow fix pass. No second reviewer. Material scope changes return to Plan.

reroute

Never silently substitute a model. Record the previous route, reason, quota verdict, new route, and new observed identity.

04 · Measured mechanical gaps

The policy is ahead of the machinery

The current fleet has strong pieces, but several critical rules still live in prose or rely on instruments that are blind to the current process shape.

A

Opus hold is not mechanically enforced

~/.bashrc · ~/.claude/settings.json

The default Claude setting remains Opus, and launchers do not check the 15:00 UTC time lock. Broadcast and Plan records are durable intent, not a dispatch gate.

B

Liveness checks see the wrapper, not Claude

agent-status.sh · epic-nudge.sh · sol-nudge.sh · plan-nudge.sh

Nested launcher shells leave tmux reporting bash while a live Claude grandchild runs. Checks that require pane_current_command=claude can call active workers stopped.

C

Desired model is not bound to observed model

.fleet-models · .model-overrides · statusline-command.sh

The fleet lacks a complete per-worker desired/observed manifest across Claude and Codex species. In-session model changes and proxy routing can escape the current intent ledger.

D

One-review policy has no per-stage lease

~/.claude/hooks/block-hot-review-loops.sh

The hook blocks known hot entrypoints, but does not count review consumption by stage. Reviewer agents and other review paths remain mechanically possible.

E

Codex quota is measured but not admitted

sol-usage.sh · quota-guard.sh · sol-nudge.sh

sol-usage.sh is robust, but dispatch does not consume its verdict. A manually written sentinel still stands between quota evidence and routing.

F

Delivery can be marked before notification succeeds

clod-squad/server.ts · squad-alerts/server.ts

Queue records may move to delivered before notification success, with no retry/dead-letter route. Cooldown markers can also advance before clod-squad send confirmation.

G

Held worktrees fall outside durability sweeps

unbacked-work-sweep.sh · sol-egress-run.sh

The sweep explicitly misses linked worktrees and uncommitted content, while Codex work is intentionally held there. Dispatch does not require a durable run receipt.

05 · Mechanical rollout

Make the cheap path the true path

Implement controls in the order that closes the largest policy-to-machinery gaps without creating another specification loop.

Time-lock and identity admission

First make prohibited model routes impossible to launch accidentally.

  • Add a fail-closed Opus hold check to normal Claude launch/dispatch paths.
  • Create one per-worker route manifest: intended species, selector, transcript-exposed model, independent proxy-side provider attestation when available, and hold state.
  • Demonstrate pre-deadline Opus red and known-good Sol/Luna green.

Process identity resolver

Replace pane-command guesses with live process ancestry and captured PIDs.

  • Resolve tmux pane → descendant Claude process from /proc.
  • Use the resolver in health, nudge, fallback, and status instruments.
  • Prove both nested-shell active and genuinely stopped arms.

Unified quota admission

Make Claude and Codex verdicts feed the same dispatch decision.

  • Consume quota-guard.sh and sol-usage.sh machine output.
  • Treat blind telemetry as unavailable capacity.
  • Serialize on slowdown, stop new starts at hard limits, and never route Fable/Opus automatically.

Review lease and evidence bundle

Move one-review cardinality from convention into state.

  • Issue one review lease per stage ID and target hash.
  • Record reviewer identity, verdict, and whether the one same-writer fix was consumed.
  • Reject duplicate review and publication without the reviewed artifact.

Atomic delivery and worktree durability

Close the gap between “sent,” “delivered,” and “preserved.”

  • Acknowledge queue delivery only after notification succeeds; add retry/dead-letter state.
  • Advance nudge cooldown only after send receipt.
  • Require each isolated worktree to emit a durable run receipt and include it in sweeps.

Terra measurement pilot

Do not assign Terra a role by aesthetics.

  • Pick one repeatable bounded task already completed by Sol and Luna.
  • Predeclare quality, wall-clock, cost, and intervention metrics.
  • Promote Terra only if measured advantage reveals a real niche.
